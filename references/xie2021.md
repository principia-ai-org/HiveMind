# An Explanation of In-context Learning as Implicit Bayesian Inference

*Authors:* Sang Michael Xie, Aditi Raghunathan, Percy Liang, Tengyu Ma
*Link:* https://arxiv.org/abs/2111.02080

## Summary

The paper addresses the puzzle of in-context learning: large language models like
GPT-3 can perform a downstream task simply by conditioning on a prompt of
input-output examples, despite never being explicitly trained to do this kind of
task adaptation.

The authors' explanation is that in-context learning emerges from a mismatch between
the pretraining distribution and the prompt distribution: pretraining documents often
exhibit long-range coherence, which requires the model to implicitly infer a latent
document-level "concept" (topic, style, or task) to predict text well. At inference
time, a prompt made of concatenated input-output examples implicitly specifies a
similar latent concept, so the model's next-token predictions amount to Bayesian
inference over which pretraining-time concept generated the prompt, and it continues
"in character" with that concept — i.e., performs the task. They formalize this with a
mixture-of-Hidden-Markov-Models generative model of pretraining data and construct a
synthetic dataset (GINC) to test the theory on both Transformers and LSTMs.

Empirically, models trained on GINC show in-context learning accuracy improving with
scale even when pretraining loss has plateaued, sensitivity to the order of in-context
examples, and settings where zero-shot performance beats few-shot — all mirroring
behaviors observed in large real-world LMs. For the citing problem, this is the
theoretical account used to justify treating role-play/in-context prompts as
conditioning that amplifies ("selects") a particular latent persona/concept the model
learned during pretraining.
