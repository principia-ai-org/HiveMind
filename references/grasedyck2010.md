# Hierarchical Singular Value Decomposition of Tensors

*Authors:* Lars Grasedyck
*Link:* https://doi.org/10.1137/090764189

## Summary

The paper (SIAM Journal on Matrix Analysis and Applications 31(4), 2010, pp. 2029–2054) introduces a hierarchical SVD for tensors of order d ≥ 2. The construction preserves key properties of the matrix SVD and reduces to the standard SVD when d = 2.

Low-rank approximations in the hierarchical format need O((d−1)k³ + dnk) parameters. The associated H-Tucker format generalizes the Tucker format and contains canonical rank-k tensors as special cases. The author develops algorithms with rigorous error analysis, with truncation complexity O((d−1)k⁴ + dnk²).

For the citing problem, it is the tensor extension of the matrix SVD that suggests decomposing the coefficient tensor of a learned polynomial along a tree.
