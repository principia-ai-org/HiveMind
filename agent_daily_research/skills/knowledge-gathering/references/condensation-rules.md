# Condensation Rules

Use these rules to decide what belongs in the daily summary, a topic note, a topic
overview, or a fortnightly review.

## Daily Summary Versus Topic Note

Keep an item only in the daily summary when:

- it is interesting but probably ephemeral
- evidence is thin or mostly vendor-framed
- it is a lead to watch rather than a durable update
- it does not answer or sharpen an active question

Create a topic note when:

- the item changes the durable understanding of a topic
- it answers, reframes, or materially advances an active question
- it includes reusable evidence, artifacts, or exact results
- it is likely to be linked from future daily summaries or overviews

Do not create a note just to increase volume.

## Updating Topic Overviews

Update only overviews affected by new durable information.

When updating:

- keep `Short Summary` below `quality.max_overview_words`
- preserve explicit uncertainty
- add durable takeaways only when they are supported by a topic note or repeated
  source-backed daily evidence
- keep open questions tied to active IDs from `QUESTIONS.md` when possible
- append note links in reverse chronological order
- avoid rewriting the whole overview when one bullet is enough

## Fortnightly Condensation

A fortnightly report should help future runs become cleaner.

Look for:

- repeated daily caveats that should become one overview caveat
- topic notes that supersede older daily fragments
- active questions that appear answered, stale, or too broad
- conflicts between sources or between recent notes and older overviews
- topics with too many low-confidence leads and not enough primary evidence

Suggested condensation should be specific enough for a future agent to act on,
for example: "merge repeated benchmark-transfer caveats into the formalisation
overview after two primary sources exist."

## What Not To Condense

Do not remove uncertainty, minority evidence, or source limitations simply to make
the knowledge base cleaner. If evidence conflicts, preserve the conflict and point
to the sources or notes that disagree.
